# 第四章搜索历史与协议

本目录汇总已有结果，不运行新的训练或参数搜索，不覆盖原始实验。

## 可直接使用的图

- `mapping_validation_history_5seeds.pdf/png`：55 维，四种映射，各五次运行；均值与样本标准差。
- `uniform_bo_validation_history_5seeds.pdf/png`：55 维均匀 BO 五次运行的独立汇总。
- `bo_vs_random_seed42.pdf/png`：同为 seed 42 的 BO 与随机搜索对照，只有一次，不能标为五次均值。

随机搜索 seeds 43–46 的匹配历史尚未找到，所以没有生成五次 BO／随机搜索对照图。不能把其他实验目录中的旧随机搜索直接拼接进来。

## 统计口径

每次运行先按评价次数计算累计最高 `score`，该列已检查等于记录级验证准确率。随后按同一评价次数对五次运行求均值及样本标准差（ddof=1）。图中准确率为百分数，差值和标准差单位为百分点。阴影不是置信区间。阶梯线避免暗示两次评价之间存在额外观测。

`mapping_history_mean_sd.csv` 为逐次均值与标准差；`mapping_histories_per_seed.csv` 保留逐种子的完整曲线；`mapping_results_per_seed.csv` 包含最终验证／测试准确率及预算检查点。

`paired_differences_vs_uniform.csv` 为同种子的“非均匀映射减均匀映射”；正值表示非均匀映射较高。`paired_difference_summary.csv` 汇总这些配对差值。验证与测试差值分别存储，不能互换。

## 主比较与补充比较

55 维主比较：固定记录划分、五折验证、每次 BO 50 次评价（16 初始）、四种映射各 seeds 42–46。随机搜索现有匹配记录仅 seed 42。

53 维补充比较：联合优化与仅优化 SVM，各五次运行；采用该实验自己的共享初始设计，不能替代主比较的某条曲线。

55／53 维精简对照：固定 1–40 Hz、5 秒预处理，比较两组相同的 50 个 C/gamma 候选，是分别调参的特征开发实验，不是完整联合 BO 对照。

## 实验协议与审查

`protocol.json` 记录主比较的特征、预算、初始化、映射、目标、数据划分、缺失运行和原始文件 SHA256。已验证20条历史均为50次、同种子四映射的划分和折一致、无记录跨训练测试或折内训练验证集合、所有训练记录恰好参与一次折验证。

种子同时改变划分及搜索随机性；各次外部划分存在重叠，且这些结果已有开发阶段使用历史。因此不得描述为五个独立外部测试集或全新确认性评价。
